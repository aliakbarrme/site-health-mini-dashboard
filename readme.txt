Dashboard widget with a 0-100 health score: updates, heavy images, missing alt text, SSL, PHP and debug checks.

== Description ==

When maintaining client sites, I want one glance to tell me what to fix. WordPress' built-in Site Health is great but long; this is the short version.

* Pending core, plugin and theme updates
* Inactive plugins you can safely remove
* Heavy images (>300 KB) with the 5 biggest listed, plus total size
* Images missing alt text (SEO + accessibility)
* PHP version check
* HTTPS / SSL status
* Debug output visible on the live site
* Discourage search engines accidentally left on
* Cached for 12 hours, refreshes after updates / uploads, Re-check button

== Installation ==

1. Upload the plugin ZIP via Plugins > Add New > Upload Plugin.
2. Activate it.
3. Open Dashboard (widget appears automatically for admins).
